# Seasonal Prey Variants

This directory contains 35+ seasonal prey variants for holiday events.

## Implementation Pattern

Each variant extends the base prey type with:
- Themed appearance (colors, effects, textures)
- Behavior modifications (speed, abilities)
- Special mechanics for seasonal events
